# ZenMart roadmap and GitHub workflow

The August Shree Shyam Store milestone checklist previously in this file is a historical snapshot. The current issue-linked sequence and decisions for each open pull request are in [ZenMart v1 — issue and PR roadmap](ZENMART_V1_PR_AND_ISSUE_ROADMAP.md). [Current engineering status](CURRENT_PRODUCTION_STATUS.md) distinguishes merged source from unverified services and release evidence.

Use [tracker #44](https://github.com/harvindertapper/Shree-shyam-store-/issues/44) as the GitHub entry point. Each implementation PR should name the issue it advances, start from current main, contain one reviewable boundary and include relevant migration, contract or device evidence. Code merged, cloud deployed, device tested and pilot approved are separate states. A closed child issue does not automatically close [pilot gate #92](https://github.com/harvindertapper/Shree-shyam-store-/issues/92).

The v1 target is direct distribution of a signed APK to five shops with at least two phones each for 14 days, after two-phone staging and clean-device recovery pass. Public launch needs a separate distribution-policy review and owner decision.
